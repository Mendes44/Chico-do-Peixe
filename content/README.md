# Conteúdo do site

Edite `site.ts` para atualizar:

- telefone, WhatsApp, e-mail, endereço e links;
- horários de funcionamento;
- categorias e itens do cardápio;
- promoções e atrações;
- fotos da galeria;
- avaliações públicas exibidas no site.

Para trocar uma imagem, coloque o novo arquivo otimizado em `public/images` e
atualize apenas o caminho correspondente em `site.ts`.
